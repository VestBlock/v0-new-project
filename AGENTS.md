# VestBlock Agent Instructions

## Creative-development work

For public-site visual work, read `docs/VESTBLOCK_CREATIVE_DEVELOPMENT_SYSTEM.md` and `docs/VESTBLOCK_HOMEPAGE_FILM_TREATMENT.md` before editing. VestBlock is a real-estate decision platform—Capital, Deals, Opportunity, routing, and DealVault—not a generic SaaS product.

- Preserve the approved VestBlock brand and conversion paths. A visual enhancement is not approval for a rebrand.
- Start with a short visual direction and storyboard. Build a scene, not a stack of template sections.
- Prefer bespoke composition, typography, material, and spatial relationships over cards, component-library patterns, or decorative glow.
- Essential copy, controls, and CTA destinations stay semantic HTML. WebGL is progressive enhancement.
- Use a finite motion vocabulary: architectural reveal, route propagation, camera push, data scan, typography mask, spatial transition, DealVault compression.
- Keep 3D code dynamically imported and isolated. Respect reduced motion, low-power devices, mobile layout, and WebGL failure.
- For new 3D assets, add an optimization report using glTF Transform / meshoptimizer before merge.
- Capture and inspect rendered screenshots at desktop, laptop, tablet, and mobile sizes. Do not self-approve from source code alone.

## Visual review

Reject a result if it could be another AI startup after swapping the logo, if the hero is taller than its story earns, if it visibly resembles a component template, or if a visual effect competes with the decision/action path.
